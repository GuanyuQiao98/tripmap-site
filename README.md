# 途迹 TripMap · 左右滑动版（静态演示）

仿制 [trip-app-orcin.vercel.app](https://trip-app-orcin.vercel.app/) 的静态版页面。

## 特点
- 单文件 HTML，无任何外部依赖，双击 `index.html` 即可打开
- **左右滑动翻页**（原生触摸滑动 + 桌面鼠标拖拽 + 滚轮横滑 + 键盘 ← →）
- 5 个页面：首页 / 行程 / 攻略 / 共创 / 设置
- 底部 Tab 导航 + 翻页指示点

## 部署到 Vercel
把本仓库导入 Vercel 即可，零配置，`vercel.json` 已包含静态站点设置。
